## Step-by-Step: Run the Project in Cursor

### Prerequisites — install these first

```bash
# 1. Install Flutter SDK
# macOS:
brew install --cask flutter

# Windows: download from https://flutter.dev/docs/get-started/install/windows
# Linux:   snap install flutter --classic

# Verify installation
flutter doctor

# 2. Install Dart (comes bundled with Flutter)
# 3. Install Android Studio (for Android emulator)
#    https://developer.android.com/studio
# 4. Install Xcode (iOS, macOS only)
#    xcode-select --install
```

### Step 1 — Open in Cursor

```bash
# Clone or copy the lingokaksha/ folder to your machine
# Then open in Cursor:
cursor /path/to/lingokaksha

# OR open from Cursor: File → Open Folder → select lingokaksha/
```

### Step 2 — Install the Flutter extension in Cursor

```
Cursor → Extensions (Cmd+Shift+X)
Search: "Flutter"
Install: Flutter (Dart Code) by Dart Code
Also install: Dart (Dart Code)

Reload Cursor after installing.
```

### Step 3 — Get dependencies

Open Cursor terminal (Ctrl+`` ` ``):

```bash
cd /path/to/lingokaksha
flutter pub get
```

### Step 4 — Generate code (Riverpod + Freezed + Hive)

```bash
flutter pub run build_runner build --delete-conflicting-outputs

# Watch mode (auto-regenerate on save during development):
flutter pub run build_runner watch --delete-conflicting-outputs
```

### Step 5 — Set up Firebase (required for auth + Firestore)

```bash
# Install Firebase CLI
npm install -g firebase-tools
firebase login

# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# Link your Firebase project (creates firebase_options.dart automatically)
flutterfire configure
# → Select your Firebase project
# → Select: Android, iOS
# → This replaces the placeholder firebase_options.dart
```

### Step 6 — Configure environment variables

```bash
cp .env.example .env
# Edit .env and add your keys:
# GROQ_API_KEY=gsk_...  (free at console.groq.com)
# OPENAI_API_KEY=sk_...  (optional, for quiz generation)
```

### Step 7 — Launch an emulator / simulator

**Android (in Cursor terminal):**
```bash
# List available emulators
flutter emulators

# Launch one
flutter emulators --launch <emulator_id>
# e.g. flutter emulators --launch Pixel_8_API_35

# OR open Android Studio → Device Manager → Create Device → Launch
```

**iOS (macOS only):**
```bash
# List simulators
xcrun simctl list devices

# Open Simulator app
open -a Simulator

# Or from Cursor: Cmd+Shift+P → Flutter: Launch Emulator → pick iPhone
```

### Step 8 — Run the app

**From Cursor (recommended):**
```
Cmd+Shift+P → Flutter: Select Device → choose your emulator
Cmd+Shift+P → Flutter: Run → picks up your selected device
```

**From terminal:**
```bash
# Run with your API keys injected
flutter run \
  --dart-define=GROQ_API_KEY=gsk_your_key \
  --dart-define=OPENAI_API_KEY=sk_your_key \
  --dart-define=API_BASE_URL=http://10.0.2.2:8000

# Hot reload: press r in terminal
# Hot restart: press R in terminal
# Quit: press q
```

**Run on a physical device:**
```bash
# Connect phone via USB, enable Developer Mode + USB Debugging
flutter devices           # confirms device is found
flutter run -d <device-id>
```

### Step 9 — See the app preview in Cursor

The Flutter extension adds a **Device Preview** panel. To see live screenshots:

```
1. Cursor sidebar → Flutter icon (looks like a wing)
2. "Flutter: Open DevTools" → opens browser-based DevTools
3. In DevTools: Inspector tab shows live widget tree with preview
```

**Recommended Cursor layout for Flutter development:**
```
Left panel:   File explorer
Centre:       Code editor
Right panel:  Flutter DevTools (Cmd+Shift+P → Flutter: Open DevTools)
Bottom:       Terminal (flutter run output + hot reload)
```

### Step 10 — Enable Device Frame preview

To see iOS/Android-framed screenshots without a real device:

```bash
# Add to pubspec.yaml dev_dependencies:
#   device_preview: ^1.1.0

# Wrap your app in main.dart:
runApp(
  DevicePreview(
    enabled: !kReleaseMode,
    builder: (context) => const LingoKakshaApp(),
  ),
);

# Then select device frames from the top toolbar in the emulator
```

## Troubleshooting

| Problem | Fix |
|---|---|
| `flutter: command not found` | Add Flutter to PATH: `export PATH="$PATH:/path/to/flutter/bin"` |
| `No devices found` | Open Android Studio → AVD Manager → Start emulator first |
| `build_runner errors` | Delete `.dart_tool/` and run `flutter pub get` again |
| `Firebase not initialised` | Run `flutterfire configure` to generate `firebase_options.dart` |
| `Groq API 401` | Check `GROQ_API_KEY` in your `.env` — get free key at `console.groq.com` |
| `iOS build fails` | Run `cd ios && pod install && cd ..` then try again |
| Android emulator slow | Enable hardware acceleration in BIOS + use x86_64 image in AVD |
| `MissingPluginException` | Run `flutter clean && flutter pub get && flutter run` |
